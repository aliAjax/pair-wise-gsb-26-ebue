# hxwl-12 心理咨询个案记录 · 录音同意与高风险转介台账

在心理咨询个案记录基础上，实现**录音同意登记**与**高风险转介**的合规台账：
同意范围、紧急联系人、到期日随个案登记；高风险会谈自动生成写明接收督导、
响应期限与安全计划的转介单；会后更正保留原因与旧值；所有动作进版本流水，
被规则阻止的操作进阻断台账（个案 / 字段 / 原值 / 规则）。

## 技术栈

React 19 + Vite + TypeScript + 原生 CSS，状态持久化在 localStorage（`hxwl-ledger-v1`），
无后端；可从侧栏"恢复演示数据"回到内置台账快照（基准日 2026-09-20）。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5112
npm run build
```

## 台账规则（src/rules.ts，界面与阻断记录共用同一措辞）

| 规则 | 内容 |
| --- | --- |
| R1 | 未取得有效录音同意（未登记 / 已撤回 / 已过期 / 范围为"不同意"）的会谈**只能保存文字摘要**，保存音频会被阻止 |
| R2 | 同意撤回必须填写原因；撤回后停止新录音，**历史录音与版本记录仍可查阅** |
| R3 | 高风险会谈**必须生成转介单**，写明接收督导、响应期限、安全计划，缺一不可登记 |
| R4 | **同一督导同一时段只接一单**，时段已占用时派单被阻止 |
| R5 | 个案存在**未被督导接收**的转介单时**不得结案** |
| R6 | 会后更正必须填写原因并**保留字段旧值**，旧值进版本流水、不得覆盖 |
| R7 | 每次加载做一致性体检：刷新后同意状态、转介接收状态与版本关系必须一致 |

## 页面

- **个案台账**：个案登记（同意范围 / 紧急联系人 / 生效与到期日）、同意撤回、
  新增会谈（高风险时同事务生成转介单）、会后更正、结案；会谈卡片展示录音载体
  （音频+摘要 / 仅文字摘要）、录制时同意快照、关联转介单状态。
- **高风险转介单**：接收督导、督导时段、响应期限（逾期标红）、安全计划全文、
  待接收/已接收状态与督导接收操作。
- **版本与阻断**：刷新一致性体检结果、阻断台账表（时间/个案/操作/字段/原值/规则）、
  倒序版本流水（登记 / 同意 / 会谈 / 转介 / 会后更正 / 结案，含旧值→新值与关系链）。

侧栏展示督导排班（可派单 / 已被哪张转介单占用）。

## 验证

- `npx tsc --noEmit` 类型检查通过，`npm run build` 构建通过。
- 33 条规则动作测试全部通过：R1 撤回/不同意/过期只存文字摘要；R2 撤回原因留痕且
  历史可查；R3 转介四要素；R4 时段冲突；R5 未接收不得结案、接收后方可结案；
  R6 更正原因与旧值保留；R7 种子数据刷新体检 0 异常。
