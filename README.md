# hxwl-12 心理咨询个案记录 · 录音同意与高风险转介台账

会谈时间线、风险等级与干预目标记录；围绕**录音同意合规**与**高风险转介闭环**的个案台账。

## 技术栈

React + Vite + TypeScript + CSS，数据通过 localStorage 持久化（刷新后同意、转介与版本关系一致）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 业务规则

### 个案登记与同意
- 登记来访者代号、咨询主题、同意范围（录音 / 督导阅档 / 教学研究，至少一项）、紧急联系人与电话、同意到期日。
- 录音同意有效 = 范围含「录音」且未撤回且未到期。
- **未取得录音同意（或撤回、过期）时，会谈只能保存文字摘要**，保存录音会被拦截。
- 同意可撤回：撤回后历史录音与历史会谈**保留可查**，但不得新增/替换录音。

### 高风险转介
- 风险等级为「高风险」的会谈保存时必须同时生成转介单，写明**接收督导、响应期限、安全计划**。
- 响应期限不得早于会谈日期。
- **同一督导同一日期同一时段只接一单**，冲突督导在下拉中置灰并提示已接个案。
- 转介单「待接收」期间**不得结案**；督导确认接收后个案方可结案。
- 会后更正把风险升级为高风险时补建转介单；更正转介字段同步留版本。

### 会后更正
- 必须填写更正原因；原因为空或无字段变更均被拦截。
- 每个变更字段生成一条版本记录：时间、个案、会谈、字段、**原值 → 新值**、更正原因。

### 受阻台账
- 所有被规则拦截的操作（登记、保存、更正、结案）统一记录：**个案、字段、原值、触发规则**。
- 页顶横幅展示最新 3 条，「更正版本与受阻」页签可查全部。

## 页面结构

1. ① 个案登记与同意（名册、同意状态徽标、撤回 / 结案）
2. ② 会谈记录（录入、录音同意门禁、转介单、会后更正、历史时间线）
3. ③ 高风险转介台账（转介单、接收确认、逾期提示）
4. ④ 更正版本与受阻（版本留痕表 + 受阻台账表）
